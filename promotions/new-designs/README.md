# Worship Duties — New Design Launch Kit

This folder contains promotional material for the three optional Worship Duties appearances currently included in the design gallery:

- **Prism** — calendar-first clarity and a focused service inspector.
- **Navy & Cream** — warm cream surfaces, navy structure, burgundy actions and gold details.
- **Aurora** — a spacious workspace with a navigation rail, dynamic schedule view and dedicated workspaces.

The promotional assets intentionally describe these as **appearance choices**, not separate apps. All three use the same Worship Duties schedule, duties, permissions and Presider song-plan data. Members can switch again from **Appearance**.

## Assets

- `index.html` — interactive launch showcase for all three designs.
- `promo.css` — styling for the showcase page.
- `prism-poster.svg` — 16:9 Prism promotional poster.
- `navy-cream-poster.svg` — 16:9 Navy & Cream promotional poster.
- `aurora-poster.svg` — 16:9 Aurora promotional poster.
- `all-designs-poster.svg` — 16:9 launch poster introducing all three choices.
- `CAMPAIGN_COPY.md` — announcement copy, short captions, headlines and CTA language.

## Art direction

The posters use abstract interface illustrations rather than screenshots so they stay clean, editable and reusable while still matching the real design systems. No religious symbols or decorative iconography are used.

### Prism

- Canvas: `#f8f9fd`
- Primary: `#3153ed`
- Ink: `#172544`
- Soft blue: `#eff3ff`
- Character: precise, bright, calendar-first, modern

### Navy & Cream

- Canvas: `#f7f3eb`
- Navy: `#253943`
- Burgundy: `#662c38`
- Gold: `#9b6d32`
- Character: warm, refined, composed, service-focused

### Aurora

- Canvas: `#f4f6fb`
- Rail: `#151d39`
- Primary: `#4555d6`
- Violet: `#7e69d9`
- Character: spacious, dynamic, desktop-workspace feel

## Exporting

The SVG files are already 1600×900 and can be opened directly in a browser, Figma, Illustrator or Preview. Export to PNG at 1600×900 for screens or 3200×1800 for high-density displays.

The showcase page is standalone and has no Firebase calls or production mutations. It exists only as campaign material.
