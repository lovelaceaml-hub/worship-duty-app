# Asset sources

No external asset ships in the selected prototype.

| Category | Source | Decision and reason |
| --- | --- | --- |
| Layout templates | None | Original local responsive layout matches the service schedule and avoids template dependency. |
| Components | None | Cards, rows, tabs, forms, and controls are authored in local CSS and native HTML. |
| Icons | None | Text controls and native form affordances make every action clear without an icon package. |
| Typography | None | Installed Georgia and Arial system fonts provide the selected serif and sans pairing. |
| Photography | None | Assignment and service content has no photographic requirement. |
| Illustration | None | The product excludes decorative religious imagery and does not need illustrations. |
| Motion | None | Local state changes and reduced-motion support cover the review without signature motion. |

The prototype has no remote stylesheet, font, image, icon, template, asset CDN, or generated media reference. The copied contract files are local validation tooling and do not add runtime dependencies.
